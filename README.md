
# Student Grade Calculator

A beginner-friendly Python project that calculates a student's total marks, average, percentage, grade, and pass/fail result.

## Features

- Accepts a student's name and marks in five subjects.
- Calculates total marks and average.
- Calculates the overall percentage.
- Assigns a grade based on the percentage.
- Checks whether the student passes or fails.
- Validates that marks are between 0 and 100.

## Technologies Used

- Python 3
- Python lists and conditional statements
- User input and basic arithmetic

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal and run:

   ```bash
   python grade_calculator.py
   ```

5. Enter the student's name and marks when prompted.

## Grading System

| Percentage | Grade |
|---|---|
| 90–100% | A+ |
| 80–89.99% | A |
| 70–79.99% | B |
| 60–69.99% | C |
| 35–59.99% | D |
| Below 35%, or any subject below 35 marks | F |
